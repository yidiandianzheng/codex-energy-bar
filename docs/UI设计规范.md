# UI 设计规范

适用于 Mini、账户、总览、今日用量与重置雷达。字体与颜色集中定义，组件按信息角色引用，避免每次局部修改另选字号或颜色。

## 字体

使用 macOS 系统字体：中文随系统回退，数字使用圆角系统字形和等宽数字，倒计时跳秒时不左右抖动。

| Mini 角色 | 基准字号 | 字重 | 用途 |
| --- | --- | --- | --- |
| caption | 10 pt | 常规 | 预计日期、重置时间、概率说明 |
| label | 10 pt | 常规 | 额度、Token、更新倒计时标签 |
| signal | 12 pt | 加粗 | 概率、倒计时数字 |
| value | 20 pt | 半粗 | 剩余额度、今日 Token |
| unit | 12 pt | 常规 | % 等单位 |

| 详情角色 | 基准字号 | 字重 | 用途 |
| --- | --- | --- | --- |
| caption | 11 pt | 常规 | 时间、来源、辅助说明 |
| body / label | 13 pt | 常规 / 中等 | 正文 / 行标签 |
| section | 13 pt | 半粗 | 分组标题 |
| rowValue | 15 pt | 加粗 | 表格主值 |
| gridValue | 17 pt | 半粗 | 今日用量数字 |
| chip | 11 pt | 半粗 | 账户卡右上角状态胶囊 |
| title | 16 pt | 半粗 | 页标题、项目名、空状态标题 |
| countdown / unit | 20 pt | 加粗 / 常规 | 倒计时 / 大数字单位 |
| metric | 28 pt | 加粗 | 概率、项目数等卡片数字 |
| heroMetric | 36 pt | 加粗 | 额度、Token 主指标 |

Mini 辅助文字至少 10 pt，账户主值 20 pt。图标使用独立 Icon 角色，不通过更改正文大小来调图标。标签不因数值的重要性一同加粗。

以上是第一档逻辑点。五档尺寸由整个面板统一缩放，字体不再单独乘缩放系数。单行数字保留现有合理缩放下限；详情正文可换行、滚动，禁止用任意更小字号去塞长内容。

## 黑白灰颜色逻辑

- 核心信息：`Color.primary`，通过字号和加粗突出。
- 标签、日期与普通图标：`Color.secondary`；装饰提示使用 tertiary。
- 背景与分隔：系统材质和低透明度中性色；悬停、选中通过淡灰底色反馈。
- 同步失败、低额度：使用明确文字和状态图标；不依赖蓝、橙、红等颜色区分。
- 账户卡右上角状态胶囊固定同一位置：推荐用浅灰实底；告急用描边加警告图标和主色半粗文字；读取失败、未配置用描边加次要文字。层级由填充、描边和字重表达，不新增色相。
- 外部来源链接：黑色文字加下划线，以形状提示可点击，不使用系统默认蓝色。
- 浅色模式深色文字，深色模式浅色文字。禁止硬编码黑色正文导致深色模式看不清。
- 已选 Logo 保留品牌资产本身的颜色，界面内容不从 Logo 派生额外强调色。

## 修改边界与检查

`Sources/CodexPetEnergy/EnergyTypography.swift` 是字体入口；`EnergyVisualStyle.swift` 是配色与表面入口。组件引用语义角色，不直接新增 `.font(.system(size: ...))`。新增角色需要说明用途并同步本规范；同一角色改动后检查相关页面。

修改完成执行：

1. `./scripts/check-ui-style.sh`：检查组件是否绕过字体或颜色入口。
2. `./scripts/test-mini-layout.sh`：检查五档界面大小、深浅模式、长数值与倒计时布局。
3. `./scripts/test-dashboard-layout.sh`：渲染四个页签及账户详情的深浅色、长内容、失败与旧值场景。
4. `./scripts/test-mini-interaction.sh`：离线临时窗口的四账户点击、拖动与可访问性检查。
5. 构建、自测及实际应用界面检查。截图中的测试概率需明确标为测试数据。

总览四列为“账户与状态 / 剩余 / 用量 / 恢复”，异常保留在对应行，来源说明可展开。Codex 主行展示最紧的额度窗口，副行展示其他窗口；详情保留全部窗口。DeepSeek 默认展示原币种金额，不用虚构总额绘制进度条。账户详情使用剩余额度、恢复时间和细横条，减少嵌套卡片。

Mini 基础尺寸 320×110 pt；有效倒计时增加 22 pt。详情基础尺寸保持 420×500 pt。五档设置称为“界面大小”，统一缩放一次。长正文通过换行和滚动适配，不持续缩小辅助文字。减少动态效果与透明度设置沿用系统。

倒计时只在来源新鲜、存在未完成且未撤回的时间预告时出现。文字为“来源预告”，与预测概率分开；不自动赋予“官方确认 100%”。字体或颜色调整不能改变该条件。
