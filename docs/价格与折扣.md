# 价格与折扣规则

省钱灯用的价格表和分时/活动折扣规则。价格是**内置静态数据，应用不联网抓价**，所以这份文档既是规则说明，也是改价格时的对照表。

核对日期：**2026-10-23 20:50（Asia/Shanghai）**。超过 30 天未核对时，应用内会提示「价格待核对」。

代码位置：`Sources/CodexPetEnergy/PricingCatalog.swift`（价格与规则）、`PricingEngine.swift`（折算与灯判定）。

## 三条基本原则

1. **积分和人民币是两套账，不混排、不换算。** WorkBuddy 走积分（有有效期、有套餐月费），DeepSeek / 豆包 / 千问 API 走人民币。积分渠道不参与人民币灯的排序，只显示「5 折 / 原价」时段状态。
2. **活动幅度以客户端为准，不写死倍率。** 社区流传的倍率（如 WorkBuddy 内置 DeepSeek 0.11x）会随活动和客户端版本变化，应用只认客户端模型选择器里的「夜间折扣」标识。
3. **灯是成本档，不是质量档。** 绿灯 ≠ 适合当前任务，红灯 ≠ 不能用。订阅额度制（Codex）成本已固定，不参与排序。

## 各渠道规则

### DeepSeek 官方 API（人民币）

| 时段 | 价格 |
| --- | --- |
| 周一至周五 09:00–12:00、14:00–18:00，且非法定节假日 | 峰时原价 |
| 其余全部时间：00:00–09:00、12:00–14:00、18:00–24:00 | 谷时 5 折 |

也就是说：工作日午休、晚上 18 点后、凌晨、整个周末都是 5 折。**不用等深夜，中午就能省。**

### 阿里云百炼 · 千问（人民币）

| 项目 | 规则 |
| --- | --- |
| qwen3.8-flash 标准价 | 输入 ¥0.8 / 百万 token，缓存命中 ¥0.1，输出 ¥2.7 |
| Batch Chat | 限时 5 折（输入 ¥0.4、输出 ¥1.35） |
| 夜间 4 折 | **仅 Qoder / Meoo 客户端 22:00–08:00，渠道专属** |

**千问 API 没有普遍分时折扣。** 夜间 4 折是客户端渠道活动，不能套到 API 报价上；个人 Token Plan 的夜间 5 折目前只覆盖 qwen3.8-max。

### WorkBuddy / WorkBuddy AI（积分渠道）

两个客户端是独立账号、独立积分，走同一套积分规则：

| 项目 | 规则 |
| --- | --- |
| 内置 DeepSeek V4.1 Flash / V4 Pro | 工作日高峰（09–12、14–18）原价积分；其余时段 + 周末 **5 折** |
| 内置 GLM-5.2 | 每晚 23:00–08:00 积分立减 |
| 内置其他模型 | 按各自积分倍率，无分时价 |

### 豆包（人民币）

**无分时折扣**，按常态价计。豆包 Seed 2.0 Mini（≤32K）折算价约 ¥0.50，是最便宜的常驻选项之一。

### Codex（订阅额度）

订阅额度制，不按 token 计价，**不参与价格灯排序**。页面上以灰字说明：订阅额度成本已固定，价格灯只回答 API / 积分渠道的边际成本。

## 时间规则

```
高峰：weekday ∈ [周一..周五] 且 非节假日 且 时间 ∈ [09:00,12:00) ∪ [14:00,18:00)
谷时：其余全部时间，含周末、法定节假日、调休上班的周末
边界：左闭右开（09:00:00 起算峰时，12:00:00 起算谷时）
时区：一律 Asia/Shanghai（北京时间，无夏令时）
```

节假日以国务院办公厅当年公布的放假安排为准，写在 `PricingCatalog` 的节假日表里，不依赖联网日历。

## 折算价与灯

按默认任务画像（输入:输出 = 5:1）折算成「¥/百万混合 token」：

```
折算价 = (5 × 输入价 + 1 × 输出价) / 6
```

| 灯 | 折算价 | 含义 |
| --- | --- | --- |
| 绿 | ≤ ¥2 | 现在跑批量、日常任务划算 |
| 黄 | ¥2–6 | 能用，但优先换绿灯，或等谷时 |
| 红 | ≥ ¥6 | 贵，留给硬任务；批量任务等谷时 |

详情页始终展开输入价 / 缓存命中价 / 输出价三行，不只给一个混合数字。

## 改价格时的约定

1. 改 `PricingCatalog.swift` 里的价格和规则，同时更新本文件的核对日期。
2. 若活动是临时的，写进对应行的 `note`，不要为了临时活动改折扣系数。
3. 改完跑 `swift run CodexPetEnergy --self-test`，价格灯相关断言在 `PricingSelfTest` 里。
