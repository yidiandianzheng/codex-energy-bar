# Codex 算力条使用说明

适用版本：v1.3.4。

## 安装与首次打开

从 [v1.3.4 下载页](https://github.com/yidiandianzheng/codex-energy-bar/releases/tag/v1.3.4) 下载 `CodexEnergyBar-v1.3.4-macOS-arm64.zip` 并解压。

在 Finder 按 **Shift + Command + G**，输入 `~/Applications` 进入用户“应用程序”文件夹；若不存在，先在个人文件夹中新建 `Applications`。把 `Codex算力条.app` 拖入该文件夹并打开，安装后的路径为 `~/Applications/Codex算力条.app`。

应用也可从系统 `/Applications` 目录运行；仓库中的安装与 CLI 脚本默认使用上述用户目录。

下载包面向 macOS 13 及以上的 Apple Silicon Mac，使用本地签名，未经过 Apple 公证；Intel 兼容性尚未验证。若系统阻止打开，先尝试启动一次，再进入“系统设置 → 隐私与安全性”，对该应用选择“仍要打开”。

应用没有 Dock 图标。桌面浮窗隐藏后，点击菜单栏算力图标即可找回；也可通过“更多 → 恢复默认位置”找回移出视野的浮窗。默认不开机自启，不安装额外后台服务。

## 日常操作

| 操作 | 方法 |
| --- | --- |
| 查看账户额度 | 点击紧凑浮窗左侧额度 |
| 查看今日项目 Token | 点击紧凑浮窗右侧 Token |
| 查看重置雷达 | 点击紧凑浮窗底部雷达摘要 |
| 移动浮窗 | 拖动紧凑浮窗，或展开页顶部的非按钮区域 |
| 收起详情 | 按 Esc，或点击收起按钮 |
| 调整尺寸、恢复位置、退出 | 打开“更多”或右键菜单 |
| 显示、隐藏浮窗 | 点击菜单栏算力图标 |
| 刷新数据 | 点击当前页刷新按钮 |

浮窗位置和五档尺寸会自动保存。界面跟随系统深浅外观，适配减少透明度和减少动态效果设置。

## 查看额度

先在本机 Codex 登录。额度页按 Codex 实际返回的数据展示各额度窗口及其重置时间；接口提供重置券时显示次数、类型和到期信息。应用只展示重置券，不会自动使用。

读取失败时显示提示并保留上次读数；没有可用数据时显示不可用。账户额度每 60 秒读取一次，手动刷新可重试。剩余百分比是账户数据，与本地 Token 统计不能直接换算。

## 查看今日算力

统计读取本机 `~/.codex/sessions` 和 `~/.codex/archived_sessions`，按 **Asia/Shanghai（北京时间）自然日**汇总。当天总量和活跃项目数覆盖全部可读项目，列表默认显示前 5 名，可切换到全部项目。

点击项目行查看完整目录与精确 Token 数。**总 Token = 输入 + 输出**；缓存输入和推理输出属于子项，不再重复加到总量中。项目占比以全部今日 Token 为分母，记录条数是日志 Token 事件数。

项目日志每 30 秒检查一次，也可手动刷新。统计只覆盖本机可读取的日志；其他电脑、未写入日志或已移除的记录不在统计范围内。

## 查看重置雷达

数据来自两个免费公开站点，无需会员或 API Key：

- [Codex Resets](https://codex-resets.com/zh-CN)：预警、公告、明确预告与重置记录。
- [codex-reset.com](https://codex-reset.com/zh/)：未来 24 小时预测，采用其[公开 API 文档](https://codex-reset.com/developers)指定的网页展示值 `probabilities.rounded_24h`。

一站有效时使用该站；两站有效且都是未来 24 小时窗口时取等权平均，例如 75% 和 45% 显示为 60%，标记“双源平均”。平均值由本应用计算，未经概率校准。不同窗口不平均，主数字保留 Codex Resets 的原口径。

两站读数都要求在 30 分钟内更新，过期观察、无效数值或尚未反映新一轮重置的数据会退出计算。缺失不等于 0%；请求失败时可能暂留仍有效的旧值，重试不会延长来源有效期。两站均不可用时显示暂无有效概率或同步状态。详情会分别列出各站原值、更新时间和来源链接。

雷达每 15 分钟同步一次，手动刷新最短间隔 60 秒；站点限流时遵守其等待时间。预告与记录使用北京时间。观察截止时间只是观察期限，预测不保证实际重置。

### 倒计时

当前选用的有效概率（双源时为平均值）在显示取整前达到 90%，且 Codex Resets 提供完整日期和时刻的额度重置预告时，浮窗增加逐秒倒计时。89.9% 即使显示为 90% 也不会触发。

倒计时由本机时钟更新，不增加网络请求。到点显示“时间已到·待确认”；来源过期、预告撤回、重置已被确认完成或概率降至门槛以下时，倒计时会取消。以 Codex 账户实际额度为准。

## 常见问题

### 额度读取失败

确认 Codex 可以正常使用，并已在本机登录。当前版本按顺序寻找下列可执行文件：

```text
/Applications/Codex.app/Contents/Resources/codex
/Applications/ChatGPT.app/Contents/Resources/codex
~/.codex/packages/standalone/current/codex
~/.local/bin/codex
```

仅在其他位置安装 CLI 时，可能无法自动识别。恢复 Codex 登录或安装后，点击额度页刷新；仍不可用时，可附上错误提示[反馈问题](https://github.com/yidiandianzheng/codex-energy-bar/issues)。

### 今日 Token 为空或更新失败

先确认今天在本机使用过 Codex。首次扫描可能需要短暂等待；没有当天记录与目录读取失败会显示不同提示。读取失败时检查上述会话目录的访问权限，再刷新。更新失败会保留上次结果。

### 雷达没有概率或一直等待

查看详情中的来源时间与错误信息。没有有效预测时不会补成 0%；网络错误或站点限流期间，等待刷新恢复即可。手动频繁点击不会绕过刷新间隔。

## 隐私与退出

本应用在本机读取会话日志并计算项目统计，不上传会话内容、项目路径或 Token 统计，不修改会话日志。账户请求由本机 Codex 处理；雷达请求会向公开数据站发送 IP 地址、应用请求标识等常规网络信息。点击原帖或来源会在浏览器打开链接。

通过“更多 → 退出”结束应用及其刷新。自动化命令和本地控制接口见 [CLI 文档](CLI.md)。
