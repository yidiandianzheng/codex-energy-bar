# 算力环使用说明

适用版本：v1.5.0（第 84 版，构建日期 2026-10-28，本地构建、尚未发布）。

## 安装与首次打开

下载与安装包见 [下载页](https://github.com/yidiandianzheng/codex-energy-bar/releases)，已公开的最新版本为 [v1.4.0](https://github.com/yidiandianzheng/codex-energy-bar/releases/tag/v1.4.0)；本文描述的是其后仍在本地构建的 v1.5.0，也可从源码构建后直接运行。

在 Finder 按 **Shift + Command + G**，输入 `~/Applications` 进入用户“应用程序”文件夹；若不存在，先在个人文件夹中新建 `Applications`。把 `算力环.app` 拖入该文件夹并打开，安装后的路径为 `~/Applications/算力环.app`。

应用也可从系统 `/Applications` 目录运行；仓库中的安装与 CLI 脚本默认使用上述用户目录。

下载包面向 macOS 13 及以上的 Apple Silicon Mac，使用本地签名，未经过 Apple 公证；Intel 兼容性尚未验证。若系统阻止打开，先尝试启动一次，再进入“系统设置 → 隐私与安全性”，对该应用选择“仍要打开”。

应用没有 Dock 图标。桌面浮窗隐藏后，点击菜单栏算力图标即可找回；也可通过“更多 → 恢复默认位置”找回移出视野的浮窗。默认不开机自启，不安装额外后台服务。

> **从旧版本升级**：应用已由「Ai算力监控」更名为「算力环」，安装路径变为 `~/Applications/算力环.app`。旧版应用不会自动删除，请手动删除 `~/Applications/Ai算力监控.app`；开启过登录自启动的，需重新执行 `scripts/enable-login-item.sh` 更新启动项。浮窗位置、尺寸与本机配置目录 `~/.config/codex-energy-bar` 沿用不变。

## 版本信息

展开浮窗后，标题栏第三行显示当前构建的版本信息，例如：

```text
v1.5.0 · 第 84 版 · 构建 2026-10-28
```

- **版本号**：语义化版本（主.次.修订），与仓库发布版本对应。
- **第几版**：本机构建号，每标记一次新的本地构建递增；同一个版本号可能有多轮构建。
- **构建日期**：打包当天（Asia/Shanghai）的日期，由构建脚本写入 App 包。

「更多 → 关于 算力环」显示同样的版本号和构建日期；`energyctl status` 返回的 `version`、`build`、`buildDate` 字段也可用于核对。完整版本记录（含每个版本改了什么、改了多少版本）见[更新日志](../CHANGELOG.md)。

从源码用 `swift run` 直接运行、或运行布局快照等未打包的程序时，标题栏会显示「开发版」，不虚构版本号。当前源码为 v1.5.0（第 84 版，构建日期 2026-10-28）。

### Mini 紧凑条

Mini 顶行显示当前在用的账户：Codex 剩余额度、DeepSeek 余额、Gemini 当前 5 小时窗口，以及已打开客户端的豆包当前时段额度、WorkBuddy 剩余积分、百度搭子积分、千问办公积分余额、Qoder CN 与 Trae CN 积分余额。豆包、WorkBuddy、百度搭子、千问办公、Qoder CN、Trae CN 客户端没有运行时（或账户未配置），对应条目不占位；首次检测到客户端打开后立即刷新，并自动出现。Gemini 登录后读取本机保存的登录态，不依赖 Gemini 应用保持运行、始终占位（未登录时按未配置隐藏）。此行为默认开启，可在「更多 → 自动隐藏未打开应用的账户」关闭；「总览」页始终列出全部账户，不受影响。下面是本机计算的使用建议行（按 Mini 条里可见的账户推荐，右侧是今日 Token）、省钱灯行（最多两条能力达标的强模型优惠）、重置雷达行和 AI 通宵行。点账户数字打开对应账户的「账户」页，键盘及辅助功能使用相同目标；拖动不会触发跳转，点建议行打开「总览」页，点今日 Token 打开「今日用量」，点省钱灯行打开「省钱灯」，点雷达行打开「重置雷达」，点 AI 通宵行开启或关闭 AI 通宵。省钱灯行默认显示，可在「更多 → 在 Mini 条显示省钱灯」关闭。

## 查看账户

「账户」页顶部可在 Codex / DeepSeek / Gemini / 豆包 / WorkBuddy / WorkBuddy AI / 百度搭子 / 千问办公 / Qoder CN / Trae CN 之间切换（三列网格排列），选中账户后显示其额度细节。Codex 先在本机登录，页面按实际返回的数据展示各额度窗口及其重置时间；接口提供重置券时显示次数、类型和到期信息。应用只展示重置券，不会自动使用。Gemini 同时显示当前 5 小时窗口与每周限额，以及已用百分比和对应用户当前订阅档位。

读取失败时显示提示并保留上次读数；没有可用数据时显示不可用。Codex 账户额度每 60 秒读取一次，手动刷新可重试。Codex 最后成功值超过 3 分钟、其他余额超过 15 分钟后自动标为旧数据，不再参与“现在使用”推荐。失败重试不会延长成功时间。剩余百分比是账户数据，与本地 Token 统计不能直接换算。

## 查看今日用量

顶部区分各自口径：Codex 为今日本机日志 Token，Gemini 为当前 5 小时窗口已用，豆包为本时段用量，DeepSeek 为今日观测消耗，WorkBuddy、WorkBuddy AI、百度搭子、千问办公、Qoder CN 与 Trae CN 在无法确认来源身份或基线时标明“今日观测未知”，其详情仍保留接口提供的本周期用量，不冒充今日积分。读数失败或过期时标记旧值；没有可信基线时为未知。各来源不做单位换算。

项目统计读取本机 `~/.codex/sessions` 和 `~/.codex/archived_sessions`，按 **Asia/Shanghai（北京时间）自然日**汇总。当天总量和活跃项目数覆盖全部可读项目，列表默认显示前 5 名，可切换到全部项目。

这一页和其他页签一样整页滚动：上面的「今日各 AI 用量」摘要固定展示，项目列表在下方向下滚动即可看全，不会被窗口底边裁切。

点击项目行查看完整目录与精确 Token 数。**总 Token = 输入 + 输出**；缓存输入和推理输出属于子项，不再重复加到总量中。项目占比以全部今日 Token 为分母，记录条数是日志 Token 事件数。

项目日志每 30 秒检查一次，也可手动刷新。统计只覆盖本机可读取的日志；其他电脑、未写入日志或已移除的记录不在统计范围内。

## 查看总览

「总览」页把 Codex 与九个额外账户汇总到一张表（账户与状态 / 剩余 / 用量 / 恢复），分别独立刷新，任一账户失败不影响其他账户；点任意一行进入该账户详情：

| 账户 | 显示内容 | 读取方式 |
| --- | --- | --- |
| Codex | 当前限制窗口的剩余百分比与对应重置时间，副行保留另一窗口 | 本机 Codex 账户额度（与「账户」页同源） |
| DeepSeek | API 账户人民币余额（优先读取 CNY） | 官方 `user/balance` 接口，使用本机已有的 DeepSeek API Key |
| Gemini | 当前 5 小时窗口与每周限额的剩余百分比、各自重置时间、订阅档位 | 读取 Gemini 应用本机登录态后调用 Google 官方用量接口 |
| 豆包 | 当前时段（滚动窗口）与近 7 天的剩余百分比、各自重置时间、套餐名 | 读取豆包客户端本机登录态后调用其额度接口 |
| WorkBuddy | 剩余积分、套餐名、本周期已用/总量 | 通过 WorkBuddy 客户端本机 IPC 只读查询 |
| WorkBuddy AI | 剩余积分、套餐名、本周期已用/总量 | 通过 WorkBuddy AI 客户端本机 IPC 只读查询 |
| 千问办公 | 剩余积分（保留 1 位小数）；有套餐总额时附剩余百分比与套餐名/到期时间 | 通过千问办公客户端本机 MCP 通道只读查询 |
| 百度搭子 | 剩余积分、套餐与赠送包的剩余/总量、到期时间 | 读取百度搭子客户端本机登录态后调用官方积分接口 |
| Qoder CN | 套餐与附加包积分剩余/总量、剩余百分比、套餐名与到期时间 | 读取 Qoder CN 客户端本机登录态后调用官方额度接口 |
| Trae CN | 权益包积分剩余/总量、剩余百分比、权益包名称与最近到期时间 | 读取 Trae CN 客户端本机登录态后调用官方额度接口 |

「今日观测」仅累计同一来源身份、同一币种、同一天连续成功采样之间的消耗。首次采样只建立基线，跨日、读取失败、长时间离线、重连或重启后重新建立基线，不追补无法归属的消耗。切换账号或币种时清除不适用的累计。旧版账本保留，但不直接当作新版可信今日值；每天北京时间零点独立切换，不等待网络成功。

DeepSeek 显示原币种金额，没有固定参考总额或余额进度条。WorkBuddy 接口当前无法提供可靠的账号身份，因此今日观测积分保持未知，本周期积分仍可显示。千问办公在套餐总额为 0（免费版或纯积分余额）时不虚构百分比，只显示剩余积分；千问办公、Qoder CN 与 Trae CN 是积分型账户，只展示余额，不参与跨账户推荐，也不会因为套餐显示 100% 就排到第一。

余额每 5 分钟自动刷新。刷新按当前页面分发：账户页只刷新所选来源，总览刷新所有来源，今日用量刷新日志和该页余额读数，雷达只刷新雷达。各来源独立进行请求和超时，某一来源故障不会锁住其他来源。

### 使用建议

页面顶部的「使用建议」由本机规则计算，不调用外部推荐 API。Codex、Gemini 和豆包同时检查所有已知的个人套餐限制窗口，任何限制窗口耗尽都不能推荐“现在使用”；Gemini 的 5 小时窗口与每周限额都参与判断，豆包活动奖励池、企业池不作为个人套餐共同限制。千问办公、Qoder CN 与 Trae CN 是积分型账户，只展示余额，不参与跨账户排名；套餐百分比（例如 498/498 = 100%）不代表额度充裕。WorkBuddy、WorkBuddy AI 与百度搭子按剩余积分占总量的百分比参与排序。重置时间只作说明，不预支未来回补。读数未知、失败或过期时退出推荐；全部不可用时不指定推荐账户。

可用时优先订阅额度，现金余额作兜底；接近用尽时标记「告急」。金额阈值只适用于对应币种，不把美元直接当人民币计算。

### 配置

可在 `~/.config/codex-energy-bar/sources.json`（权限 0600）补充凭证，菜单「更多 → 打开余额配置文件」会自动生成模板：

```json
{
  "deepseek": { "apiKey": "sk-..." },
  "doubao": { "cookie": "", "productLine": "" },
  "gemini": { "enabled": true },
  "workbuddy": { "enabled": true },
  "workbuddyintl": { "enabled": true },
  "dumate": { "enabled": true },
  "qwenwork": { "enabled": true },
  "qoder": { "enabled": true },
  "trae": { "enabled": true }
}
```

- DeepSeek Key 按「配置文件 → `DEEPSEEK_API_KEY` 环境变量 → 本机 WorkBuddy 里已配置的 DeepSeek 模型」顺序查找，通常无需填写。
- 豆包默认读取客户端登录态；如果 macOS 弹窗询问是否允许访问「DoubaoWork Browser Safe Storage」，点允许即可。拒绝时可在弹窗说明中按提示重试，或在配置里手填 `doubao.cookie`。
- 豆包只读取明确的当前 profile（Default / Profile 2 …）。有多个 profile 且无法判断当前账号时会提示无法确认，不尝试旧账号。显式配置的 Cookie 由用户自行维护。
- Gemini 需要 Gemini 应用在本机登录过；关闭应用不影响读取，账户始终显示在 Mini 条。第一次读取需要 macOS 钥匙串授权（条目「Gemini Safe Storage」），点允许即可；拒绝或取消后该账户显示未授权，可随时重试。登录过期时在 Gemini 应用重新登录。
- WorkBuddy 需要客户端保持运行；关闭客户端时该行显示「WorkBuddy 未运行」，不影响其他账户。
- 千问办公需要客户端保持运行；关闭客户端时该行显示「千问办公未运行」，不影响其他账户。读取通过客户端的本机 MCP 通道完成，不读取或保存其登录 token。
- 百度搭子需要客户端在本机登录过；关闭客户端时该行显示「百度搭子未运行」，不影响其他账户。读取只使用它自己的登录数据（内存中解密），Cookie 不落盘、不外传。
- Qoder CN 需要客户端在本机登录过；关闭客户端时该行显示「Qoder CN 未运行」，不影响其他账户。读取在内存中解密客户端自己的登录文件，token 不落盘、不外传。第一次读取钥匙串时 macOS 可能询问是否允许算力环访问「Qoder CN App Safe Storage」，点允许即可。
- Trae CN 需要客户端在本机登录过；关闭客户端时该行显示「Trae CN 未运行」，不影响其他账户。读取在内存中解密客户端全局状态里的登录信息，不需要钥匙串，token 不落盘、不外传。没有积分权益包时提示在客户端领取或升级后重试。

## 查看省钱灯

Mini 条中的「省钱灯」行默认显示最多两条强模型优惠：能力达标的免费额度优先，其次是正在打折、性价比最高的模型；优惠超过两条时提示「共 N 条」。点它进入「省钱灯」页，页面把正在打折的模型排在前面，同组再按「折算价」从低到高列出：

- **灯色**：绿 = 现在用最划算；黄 = 中等，优先换绿灯或等谷时；红 = 贵，留给硬任务或等谷时。红灯不代表模型差，绿灯也不代表适合当前任务。
- **推荐门槛**：按公开评测网数据标定 0–100 能力分，≥88（DeepSeek Flash 90 附近）才进入 Mini 推荐。当前 Hy4 preview 94、Step-5-Preview 93 达标；Step-5 与 Hy3 的限免均已于 2026-10-28 结束，已移出免费额度。Hy3 能力 86，不达标。免费或折扣只改变价格，不抬高能力；弱模型再便宜也不占用推荐位。
- **免费状态核验**：有官方结束日期的活动按日期判断；没有明确结束日期的限免活动，超过 3 天未复核会标「待核对」，不再按免费推荐。
- **折算价**：默认按「输入 5 : 输出 1」折算成每百万混合 Token 的价格，缓存命中按 0% 计算；完整输入价、缓存命中价和输出价写在同一行。
- **打几折**：有分时价的模型在灯旁标出当前档位，例如「谷时 5折」「峰时原价」；无分时价的模型写「常态价 / 无分时折扣」。折扣胶囊用橙色表示活动价，常态价与峰时原价用中性灰，不把原价显示成绿色。DeepSeek 官方、WorkBuddy 内置 DeepSeek 的 5 折规则，千问 Night Plan 的 4 折，GLM-5.2 的夜间立减，都单独列在「积分 / 订阅渠道」中。
- **下次变价**：每个模型/渠道显示距下次谷峰切换或折扣开始/结束的倒计时。DeepSeek 周末和法定节假日全天谷时，调休上班的周末也按谷时。
- **积分 / 订阅渠道**：WorkBuddy 积分、千问积分、Codex 订阅额度不与人民币混排，只显示各自的分时折扣和状态；Codex 与千问办公标明「订阅额度，无分时价」。
- **价格日历**：列出已知的未来价格节点，例如 2026-11-01 起 DeepSeek Search / Fetch 按次收费，以及 2027 年节假日表待更新。

价格数据是应用内置的静态表（核对日期显示在页面顶部），使用时不联网抓取价格页；超过 30 天未核对会标「价格待核对」。免费额度另外按 3 天核验窗口处理，避免把已经结束的限免继续当免费。页面只读本机价格表，不改变任何账户或订阅。

## 查看重置雷达

数据来自两个免费公开站点，无需会员或 API Key：

- [Codex Resets](https://codex-resets.com/zh-CN)：预警、公告、明确预告与重置记录。
- [codex-reset.com](https://codex-reset.com/zh/)：未来 24 小时预测，采用其[公开 API 文档](https://codex-reset.com/developers)指定的网页展示值 `probabilities.rounded_24h`。

一站有效时使用该站；两站有效且都是未来 24 小时窗口时取等权平均，例如 75% 和 45% 显示为 60%，标记“双源平均”。平均值由本应用计算，未经概率校准。不同窗口不平均，主数字保留 Codex Resets 的原口径。

**来源预告**：Codex Resets 公布带日期和时刻的有效重置预告时，显示“来源预告”与北京时间倒计时；这是第三方来源的时间声明，与预测值分开，不自动赋予“官方确认 100%”。预告撤回、完成、来源过期或超过预告时刻 2 小时后，相关文字与倒计时一并清除。

两站读数都要求在 30 分钟内更新，过期观察、无效数值或尚未反映新一轮重置的数据会退出计算。缺失不等于 0%；请求失败时可能暂留仍有效的旧值，重试不会延长来源有效期。两站均不可用时显示暂无有效概率或同步状态。详情会分别列出各站原值、更新时间和来源链接。

雷达每 15 分钟同步一次，手动刷新最短间隔 60 秒；站点限流时遵守其等待时间。预告与记录使用北京时间。观察截止时间只是观察期限，预测不保证实际重置。

### 倒计时

存在有效来源预告时，浮窗增加逐秒倒计时，目标为 Codex Resets 公布的预告时刻；没有有效时间预告时，即使来源概率很高也不显示倒计时。倒计时由本机时钟更新，不增加网络请求。

到点显示“时间已到·待确认”；来源过期、预告撤回、重置已被确认完成或超过预告时刻 2 小时时，倒计时会取消。以 Codex 账户实际额度为准。

## AI 通宵（夜间 AI 通宵模式）

AI 通宵让 Mac 在屏幕关闭后继续运行，适合睡前让 AI 后台任务、下载或长时间生成继续跑。它等同于系统的“防休眠”（`caffeinate -i`）：只阻止 Mac 因空闲进入系统睡眠，不阻止显示器睡眠。

- **开启**：点击 Mini 条底部「AI 通宵」行右侧的「开启」，或「更多 → 开启 AI 通宵」。开启后立即关闭全部显示器（内置屏和外接屏一起关），并在 1 秒、3 秒后再各补一次关屏，避免点击的残余键鼠事件把屏幕立刻唤醒，Mini 条显示已开启时长。
- **关闭**：再次点击同一行的「关闭」，或「更多 → 关闭 AI 通宵」，恢复系统默认休眠。退出应用时也会自动关闭。
- **低电量自动关闭**：使用电池且电量不高于 15% 时，应用会在 15 秒内自动关闭 AI 通宵，Mini 条提示「电量 N%，已自动关闭」约十分钟；插电时不会自动关闭。
- **不改系统设置**：不修改 `pmset` 配置、不需要管理员密码、不安装后台服务；只在本应用运行期间持有系统防休眠断言。
- **合盖仍会休眠**：macOS 对合上 MacBook 上盖有独立规则，AI 通宵只在开盖时有效。屏幕可以全黑，但请保持上盖打开。
- **建议连接电源**：长时间运行会持续耗电；低电量保护只是兜底，睡前最好直接接电源。
- **网络与任务**：网络、AI 客户端和后台进程照常运行；AI 通宵不会代替各 AI 客户端自己的任务队列。

如果只想让屏幕休眠、不阻止系统睡眠，不需要开启 AI 通宵，等系统按默认时间熄屏即可。

## 常见问题

### 额度读取失败

确认 Codex 可以正常使用，并已在本机登录。当前版本按顺序寻找下列可执行文件：

```text
/Applications/Codex.app/Contents/Resources/codex
/Applications/ChatGPT.app/Contents/Resources/codex
~/.codex/packages/standalone/current/codex
~/.local/bin/codex
```

仅在其他位置安装 CLI 时，可能无法自动识别。恢复 Codex 登录或安装后，点击账户页刷新；仍不可用时，可附上错误提示[反馈问题](https://github.com/yidiandianzheng/codex-energy-bar/issues)。

### 今日 Token 为空或更新失败

先确认今天在本机使用过 Codex。首次扫描可能需要短暂等待；没有当天记录与目录读取失败会显示不同提示。读取失败时检查上述会话目录的访问权限，再刷新。更新失败会保留上次结果。

### 雷达没有概率或一直等待

查看详情中的来源时间与错误信息。没有有效预测时不会补成 0%；网络错误或站点限流期间，等待刷新恢复即可。手动频繁点击不会绕过刷新间隔。

## 隐私与退出

本应用在本机读取会话日志并计算项目统计，不上传会话内容、项目路径或 Token 统计，不修改会话日志。账户请求由本机 Codex 处理；雷达请求会向公开数据站发送 IP 地址、应用请求标识等常规网络信息。点击原帖或来源会在浏览器打开链接。AI 通宵只在本机申请系统防休眠并调用系统自带 `pmset` 关闭显示器，电量保护只读取本机电池状态，不联网、不写入系统电源配置。

通过“更多 → 退出”结束应用及其刷新，同时解除 AI 通宵。自动化命令和本地控制接口见 [CLI 文档](CLI.md)。
