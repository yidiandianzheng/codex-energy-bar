## 模型排行榜（每日更新 1 次）

> 提出：2026-10-24。用户目标：**快速发现最近冒出来的强模型，好马上去试**。不是做评测机构，是做个人"该试谁"的决策看板。

### 设计原则：一个数据源，多个视角榜

同一份抓取结果，切成 3+1 个榜单视图。这样只需一套抓取逻辑，维护成本最低，也避免"综合分"把信息压平。

| 榜 | 回答的问题 | 排序依据 |
|---|---|---|
| **① 推理能力榜** | 谁最强？ | 综合能力分（Arena Elo / LiveBench / 基准均分） |
| **② 性价比榜** | 谁最划算？ | 能力分 ÷ 混合单价，单位成本换到的能力越高越靠前 |
| **③ 价格榜** | 谁最便宜？ | 混合单价升序（$/M token），纯成本视角，方便快速筛"能随便造"的模型 |
| **④ 新秀雷达**（附加） | 最近有什么新东西？ | 近 30 天上线/更新的模型，按能力分排序，标记"值得试" |

④ 是你真正的需求落点：**推理能力告诉你谁强，性价比告诉你值不值，新秀雷达告诉你该先试谁**。

### 性价比怎么算（建议公式）

```
混合单价 BlendedPrice = 0.75 × input_$/M + 0.25 × output_$/M   （输入为主、输出溢价）
性价比 Value          = 能力分 / BlendedPrice
性价比指数            = Value / 榜内最高 Value × 100          （归一化到 0–100，方便看）
```

- 输出单价通常 4–5 倍于输入，混合比例可按你实际用法调（跑 Agent 长上下文 → 输入权重更高）。
- 免费的模型 BlendedPrice = 0，需单列"免费"标签而非做除法。
- 建议保留"能力门槛"过滤：低于某个分数线的模型不进性价比榜前排，否则便宜的弱模型会霸榜。
